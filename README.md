# RT·ПУЛЬТ — голосовой агент на OpenRouter

Одностраничное веб‑приложение (полудуплексный голосовой агент). Записывает речь с микрофона и
прогоняет её через каскад из трёх моделей на **OpenRouter REST API**:

1. **STT** — `openai/whisper-large-v3-turbo` (`/api/v1/audio/transcriptions`) расшифровывает речь.
2. **LLM** — текстовая модель (по умолчанию `openai/gpt-4o-mini`, выбирается в интерфейсе) генерирует ответ.
3. **TTS** — `microsoft/mai-voice-2-flash` (`/api/v1/audio/speech`) озвучивает ответ.

Цикл «запись → whisper → llm → mai-voice → динамик» занимает 2–6 секунд (это не настоящий
realtime). Каждый этап каскада виден в интерфейсе отдельным блоком с таймингом.

Весь код — HTML + CSS + JS — лежит в одном файле `index.html`. Сборка не нужна: это чистая
статика, которую можно хостить где угодно.

## Возможности

- **Push-to-talk** (кнопка или пробел) и **авторежим** с детекцией тишины.
- Осциллограф PCM16, VU‑метр микрофона, лампы ключ / микрофон / эфир / динамик.
- Блоки STT / LLM / TTS с таймингом каждого этапа каскада.
- Выбор LLM («мозг» агента) прямо в интерфейсе: `gpt-4o-mini`, `gemini-2.5-flash`, `claude-haiku-4.5`,
  `openrouter/auto` или произвольная модель.
- Пресеты сценариев (холодный звонок, входящий лид, приём заказов) и редактируемый системный промпт.
- Проба голосов TTS прямо на главной странице (кэшируется, повторное прослушивание бесплатно).
- Журнал диалога, экспорт диалога в `.txt`.
- Счётчики реплик, токенов и приблизительной стоимости.

## Что нужно для работы

- **HTTPS или `localhost`** — иначе браузер не даст доступ к микрофону.
- **Ключ OpenRouter** (`sk-or-...`) — вводится в интерфейсе, хранится **только в браузере**
  (`localStorage`), на сервер не передаётся. Запросы идут напрямую на `openrouter.ai`.
- Браузер с Web Audio API (Chrome / Edge / Firefox).

## Локальный запуск

```bash
# из корня репозитория
python -m http.server 8000
# затем открой http://localhost:8000
```

Открывать `index.html` как `file://` не рекомендуется — часть браузерных API работает только
в secure context (`https`/`localhost`).

## Деплой

Приложение — статический `index.html` в корне, поэтому подходит любой статический хостинг.

### Vercel
```bash
npm i -g vercel
vercel        # предпросмотр
vercel --prod # прод
```
Или подключи репозиторий на vercel.com — фреймворк «Other», build‑команда не нужна.

### Netlify
```bash
npm i -g netlify-cli
netlify deploy --dir=. --prod
```
Publish directory — корень репозитория, build‑команда пустая.

### GitHub Pages
Settings → Pages → Source: ветка с этим файлом, папка `/ (root)`. Страница поднимется по HTTPS.

## Лаборатория моделей (`lab.html`)

Отдельная страница для сравнения аудио‑моделей OpenRouter на русском:

- **TTS** — одна фраза прогоняется через все голосовые модели (`/api/v1/audio/speech`),
  каждую можно прослушать и переслушать из кэша. Поля модели и голоса редактируемые.
- **STT** — одна запись (микрофон или загруженный файл) прогоняется через все модели
  распознавания (`/api/v1/audio/transcriptions`), расшифровки сравниваются рядом.

Помогает выбрать лучшую связку «распознавание речи + озвучка» перед вшиванием в агента.

## Приватность

Ключ и настройки хранятся в `localStorage` браузера. Аудио и текст уходят только в OpenRouter
по HTTPS. Собственного бэкенда у приложения нет.
