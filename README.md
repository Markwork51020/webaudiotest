# RT·ПУЛЬТ — голосовой агент на OpenRouter

Одностраничное веб‑приложение: голосовой агент на каскаде **STT → LLM → TTS**.
Записывает речь с микрофона, распознаёт, отвечает через LLM и озвучивает ответ
нативным русским голосом. Весь код — в одном файле `index.html`, сборка не нужна.

## Пайплайн

| Шаг | Модель |
|-----|--------|
| **STT** | `openai/whisper-large-v3-turbo` (язык `ru`) |
| **LLM** | выбирается в интерфейсе (`openai/gpt-4o-mini` по умолчанию) |
| **TTS** | `minimax/speech-2.8-turbo` (или `-hd`), mp3 |

Голоса — нативно русские, без иностранного акцента:

- `Russian_AmbitiousWoman` — женский
- `Russian_HandsomeChildhoodFriend` — мужской

Цикл «запись → whisper → llm → minimax → динамик» занимает ~2–6 секунд.
Это не realtime: перебиваний нет.

## Возможности

- **Push-to-talk** (кнопка или пробел) и **авторежим** с детекцией тишины.
- Осциллограф микрофона и ответа агента, индикаторы этапов конвейера с таймингами.
- Пресеты сценариев (холодный звонок, входящий лид, приём заказов) и редактируемый
  системный промпт.
- Журнал диалога с экспортом, счётчики реплик, токенов, стоимости и времени цикла.
- Все настройки (ключ, модели, голос, промпт, пороги авторежима) сохраняются в
  `localStorage`.

## Что нужно для работы

- **HTTPS или `localhost`** — иначе браузер не даст доступ к микрофону.
- **Ключ OpenRouter** (`sk-or-...`) — вводится в интерфейсе, хранится только в
  браузере, на сервер не передаётся. Запросы идут напрямую на `openrouter.ai`.

## Локальный запуск

```bash
python -m http.server 8000
# открыть http://localhost:8000
```

## Деплой

Статика с `index.html` в корне — подходит любой статический хостинг.

- **Vercel:** импортировать репозиторий (Framework = Other, build пустой) или `vercel --prod`
- **Netlify:** `netlify deploy --dir=. --prod`
- **GitHub Pages:** Settings → Pages → root

`vercel.json` задаёт security‑заголовки, включая `Permissions-Policy: microphone=(self)`.
