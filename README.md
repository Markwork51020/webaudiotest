# RT·ПУЛЬТ — голосовой агент на OpenRouter

Одностраничное веб‑приложение (полудуплексный голосовой агент). Записывает речь с микрофона,
отправляет её в модель `openai/gpt-audio` через **OpenRouter REST API** и проигрывает голосовой
ответ. Цикл «запись → запрос → ответ» занимает 2–5 секунд (это не настоящий realtime).

Весь код — HTML + CSS + JS — лежит в одном файле `index.html`. Сборка не нужна: это чистая
статика, которую можно хостить где угодно.

## Возможности

- **Push-to-talk** (кнопка или пробел) и **авторежим** с детекцией тишины.
- Осциллограф PCM16, VU‑метры входа/выхода, лампы REC / ЗАПРОС / ДИНАМИК.
- Пресеты сценариев (холодный звонок, входящий лид, приём заказов) и редактируемый системный промпт.
- Расшифровка речи через Web Speech API (если доступен в браузере).
- Журнал диалога + HTTP‑лог, экспорт диалога в `.txt`.
- Счётчики реплик, токенов, приблизительной стоимости и TTFT.

## Что нужно для работы

- **HTTPS или `localhost`** — иначе браузер не даст доступ к микрофону.
- **Ключ OpenRouter** (`sk-or-...`) — вводится в интерфейсе, хранится **только в браузере**
  (`localStorage`), на сервер не передаётся. Запросы идут напрямую на `openrouter.ai`.
- Браузер с Web Audio API (Chrome / Edge / Firefox).

## Локальный запуск

```bash
# из корня репозитория
python -m http.server 8000
# затем открой http://localhost:8000
```

Открывать `index.html` как `file://` не рекомендуется — часть браузерных API работает только
в secure context (`https`/`localhost`).

## Деплой

Приложение — статический `index.html` в корне, поэтому подходит любой статический хостинг.

### Vercel
```bash
npm i -g vercel
vercel        # предпросмотр
vercel --prod # прод
```
Или подключи репозиторий на vercel.com — фреймворк «Other», build‑команда не нужна.

### Netlify
```bash
npm i -g netlify-cli
netlify deploy --dir=. --prod
```
Publish directory — корень репозитория, build‑команда пустая.

### GitHub Pages
Settings → Pages → Source: ветка с этим файлом, папка `/ (root)`. Страница поднимется по HTTPS.

## Приватность

Ключ и настройки хранятся в `localStorage` браузера. Аудио и текст уходят только в OpenRouter
по HTTPS. Собственного бэкенда у приложения нет.
